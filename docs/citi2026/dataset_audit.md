## Risks for summarization evaluation

- Reference quality: 2139 descriptions are shared by multiple records, so the same reference can be paired with different transcriptions.
- Duplicates: 2641 duplicate transcription rows can inflate effective sample size and bias bootstrap confidence intervals.
- Eligibility: only documents with at least 100 words are used, which excludes short notes and may shift results toward long-document behaviour.
- Missing values: loader does not drop empty descriptions; rows with blank references would score as zero or be silently included.
